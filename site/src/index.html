A few useful answers

BEFORE YOU
JUMP IN.

Does every request turn into a brainstorm?+

No. Research, diagnosis, comparison, exact edits and execution need different work. A simple task can stay simple, and an explicit format or count takes priority.

Can it carry out the work?+

When your host has the tools and you authorize the action, it can help create, revise and check actual outputs. Otherwise it can prepare a usable handoff and explain what remains. A plan is not proof of execution.

What about separate thinkers and critics?+

Independent review is available when the host supports and permits it. Otherwise, Idea-Man must label a sequential review as non-independent. Scores are optional judgments; they do not prove quality or predict audience response.

Will it remember the project?+

With your authorization, local records can preserve decisions, constraints and pending work. On resume, sources and current conditions need checking. Idea-Man does not automatically sync memory across chats or install a background observer.
