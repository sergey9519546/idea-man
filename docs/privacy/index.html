PRIVACY.

Know where your work goes.

Effective October 23, 2026

What Idea-Man provides

Idea-Man, published by Sergey Avetisyan, is a package of agent skills, reference material, and an optional local Python planner. It does not operate an Idea-Man backend or a separate account system.

Your host handles your conversations

Your requests, files and generated outputs are processed by the host application and model you use. If you authorize connected tools or external services, those services may receive the information needed for the task. Their terms, privacy policies, settings and retention practices apply. Check those policies before sharing sensitive information.

Optional local records

Idea-Man can help save and resume project records locally when you authorize that workflow. These records may contain project context and scoped correction notes. You control the local files and can inspect or delete them using your normal file tools. The packaged plugin does not install a background observer, raw-prompt logger, model training process, automatic global learning, or cross-chat synchronization.

This website

This static website includes no Idea-Man analytics, advertising trackers, third-party font scripts, contact form, or payment collection. Prompt-copy controls use your browser’s clipboard only when you activate them. The hosting provider may process ordinary request information such as IP addresses and request logs under its own policies.

Public support

GitHub issues and contributions are public and governed by GitHub’s policies. Do not include secrets, private documents or personal information. A support request may be used to investigate and address the issue you report.

Questions or changes

Use the support page for privacy questions about Idea-Man. This page may change as the plugin evolves; the effective date will reflect updates.
