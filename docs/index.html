01 / How it works

UNDERSTAND FIRST.
THEN IDEAS.

Most brainstorming starts generating before it understands the problem. Idea-Man does it in the other order.

  1. 01

    Diagnose the problem.

    What are you really trying to solve, for whom, with what constraints? The brief gets sharpened before the work begins.

  2. 02

    Find the insight.

    The true thing about people or the situation that opens up a better answer. When you need ideas, this is where they start.

  3. 03

    Generate far past the obvious.

    Lateral, systems, divergent thinking and more. Different methods push past the first ideas everyone has.

  4. 04

    Challenge the weak ones.

    Honest critique, clear risks and the cheapest useful test. A separate critic joins in when your host supports it.

✳

Need research, a decision, a precise edit or the finished work? Idea-Man takes the route that fits. You can just ask.

Example

Why are Friday repairs always late?

“Our bike shop promises Friday pickup, then spends Friday calling customers to apologise. We have three mechanics and this month's job log. Find what's going wrong before we hire anyone.”

How it could help

Check where jobs wait: approval, parts, or repair. If parts are the delay, try setting pickup dates after they arrive. Use the log to check that explanation first.

05 / Sample output

WHAT YOU ACTUALLY GET.

Brief
A tiny coffee roaster has $5,000 to launch decaf. It already sells at a Saturday market. Same stall, same team.
Working hypothesis
Some customers skip coffee after dinner because of caffeine. A small decaf bag could let them keep that ritual. Check this with customers at the stall.
The idea
One more cup. Sell a small take-home bag for after dinner. Let people taste the decaf at the stall first. Sign: “Save a cup for after dinner.” Keep “decaf” clear on the bag.
Why try it
A taste answers “Will I like it?” A small bag lowers the cost of trying it at home.
Passed over
  • A full packaging run commits money before learning whether anyone wants it.
  • Free bags mix up interest in decaf with interest in a freebie.
First test
Cap one Saturday's tasting at $200. Price the small bag to cover coffee and packaging. Count tasters and paid purchases; ask buyers when they'd drink it and non-buyers why they passed. Check costs and feedback before spending more.

Illustrative response written for this page, not a customer result or a recorded plugin run. The idea and test are proposals.

06 / Install

GET Idea-Man.

Get the plugin ZIP ↗View on GitHub ↗

Free plugin · No in-plugin purchases

01Claude.ai & CoworkUpload the plugin ZIP+

  1. Download the plugin ZIP from GitHub Releases. Choose the plugin asset, rather than GitHub’s source-code archive.

  2. Open Customize → Plugins → Add → Upload plugin and choose the ZIP. In Cowork, open the Cowork tab first.

  3. In a conversation, type / to choose an Idea-Man skill, then send your brief.

Requires a paid Claude plan with plugin access.

02Claude CodeInstall from your terminal+

  1. Add the marketplace and install Idea-Man from your terminal.

    claude plugin marketplace add sergey9519546/idea-man
claude plugin install idea-man@idea-man-marketplace

  2. Start a new Claude Code session. Run /idea-man:creative-director followed by your brief.

03CodexAdd the repository marketplace+

  1. Add the repository marketplace from your terminal.

    codex plugin marketplace add sergey9519546/idea-man --ref main

  2. Restart the desktop app. Open the Plugins Directory, choose the Idea-Man marketplace, and install Idea-Man. In Codex CLI, open /plugins.

  3. Start a fresh chat. Select Idea-Man's Innovation Conductor, or type $idea-man:creative-director followed by your brief.

This uses the repository marketplace. A public directory listing is not required.
