Let’s get you unstuck.

Get help with Idea-Man

Idea-Man is published by Sergey Avetisyan as a free plugin. Use the public GitHub issue tracker for installation problems, reproducible bugs, feature requests or questions about the packaged skills.

Open a GitHub issue ↗

Include what helps

  • Your host application and version, operating system, and Idea-Man version.
  • The steps that led to the issue, what you expected, and what happened.
  • A small, non-sensitive example and relevant error text.

GitHub issues are public. Do not post passwords, API keys, private documents, personal information, or confidential conversation history. Redact sensitive details before sharing.

Host or connected-service questions

Account access, billing, host availability, model behavior and third-party tool connections are managed by their respective providers. Contact the relevant provider when an issue is outside Idea-Man’s packaged skills or local planner.

Support is provided as available; no response-time or availability guarantee is offered.
