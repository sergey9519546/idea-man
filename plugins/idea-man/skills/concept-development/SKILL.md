# Develop the chosen idea

Apply ../creative-director/references/studio-router.md and
../creative-director/references/studio-protocol.md.

Identify the selected concept from context and inspect its source. Preserve its core
mechanism and approved properties. Choose with a short rationale when selection is
delegated. If a consequential selection is neither made nor delegated, ask. Several
approved concepts can remain separate active branches.

Produce concrete substance appropriate to the stage:
| Domain | Development pack |
|---|---|
| Film / short | Logline, character desire/contradiction, causal beats, ending, signature scenes, production limits |
| Series / animation | Lead, world rules, repeatable engine, pilot beats, contrasting episodes, visual invariants |
| Character / identity | Silhouette, behavior, proportions, expression rules, palette/materials, pose/state range, reference board |
| Campaign | Audience action, core experience, message/channel adaptations, sequence, resources, measurement |
| Product / feature | User problem, flow, states/errors, smallest useful version, acceptance criteria, experiment |
| Game | Player fantasy, loop, meaningful choice, feedback, failure/recovery, playable first slice |
| Music / video | Creative rule, actual music relationship, images/progression, production approach; verified timestamps only |
| Name / verbal identity | Territory, requested shortlist, pronunciation/context, usage system, checks still needed |
| Engineering / operations | Evidence-supported problem, change, dependencies, failure cases, reversible rollout, measurement |

Use ../creative-director/references/output-templates.md as craft guidance, not a mandate
for irrelevant sections. Do not give a film an episode engine or invent a budget because
a template has a budget field.

Each detail must strengthen the selected idea. Separate decided, proposed and unknown
details. Produce the requested document/artifact with host tools. If implementation was
also requested, continue to ../execution-handoff/SKILL.md without an unnecessary pause.

## Innovation integration

For general innovation and practical problem solving, use ../innovation-strategy/SKILL.md. For evidence-led articles and reports, use ../research-and-writing/SKILL.md. Verify the resulting artifact through ../artifact-quality/SKILL.md with the relevant rubric; do not duplicate a full critique.
