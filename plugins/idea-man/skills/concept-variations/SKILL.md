# Controlled variations

Apply ../creative-director/references/studio-router.md and
../creative-director/references/studio-protocol.md.

1. Inspect the exact reference/version and feedback. Resolve numbered choices against
   their original board. Never substitute a similarly named favorite.
2. Identify locked identity, features, palette, audience, premise or requirements, and
   dimensions allowed to vary.
3. Classify explore (different mechanisms), refine (chosen mechanism) or edit (specific
   properties). For edit use the director's revision contract; a concept sheet is wrong.
4. Build a variation matrix. Use domain-specific axes: story engine/conflict/world rule;
   visual silhouette/proportions/material/gesture; product job/flow/incentive/constraint;
   campaign behavior/medium/reveal. Each idea needs a different core move, not just styling.
5. Generate the requested count. For invention use several real thinking procedures from
   ../creative-director/references/thinker-arsenal.md. Avoid rejected mechanics unless
   the user asks to revisit them.
6. Describe each candidate in one sentence, compare mechanisms, replace duplicates.
   Do not pretend originality is mathematically measured. Label exploratory candidates.
7. When the user wants images, use the available image tool with actual references.
   Keep names/numbers stable. Inspect count, legibility, locked properties and variety.
   Deliver the visual, not only a prompt. If unavailable, label the execution brief.

After rejection distinguish a weak concept from failed execution. After repeated misses,
change the relevant mechanism/axis and state your diagnosis as a hypothesis. Do not add
removed facial features to make a minimal character expressive; use the remaining
design variables. Preserve approved constraints across tools and retries.

Present the requested alternatives and their meaningful differences. A useful shortlist
is a recommendation; it is not user approval or permission to discard other favorites.

For a diagnosed structural, reframing or divergence obstacle, load only the matching section of ../creative-director/references/supplementary-methods.md via the mode map in thinker-arsenal.md. These subprocedures preserve the existing mode IDs, requested count and locked reference properties; none requires a fixed method combination.
