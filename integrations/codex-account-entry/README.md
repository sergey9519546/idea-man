# Optional local Idea-Man compatibility entry

The preferred Codex path is the supported repository marketplace:

```text
codex plugin marketplace add sergey9519546/idea-man --ref main
codex plugin add idea-man@idea-man-marketplace
```

Start a fresh chat and select **Idea-Man - Innovation Conductor**, or invoke
`$idea-man:creative-director`. A bare `$creative-director` can select another
installed skill. Keep the current source enabled and disable an obsolete Idea-Man
installation if both sources expose that same qualified name; preserve its files.

This folder is a compatibility entry for a machine that already has a standalone
`$idea-man` shortcut and the private account package in Codex's account cache. It is
not an additional packaged specialist and is not needed for normal repository
installation. Preserve an existing shortcut before replacing its entry and adding
the resolver. Do not replace unrelated creative-director skills.

The read-only resolver accepts exactly one complete version under
`~/.codex/plugins/cache/created-by-me-remote/idea-man`. It validates package identity,
version and required files, then loads the current conductor and its governing
references. Missing or ambiguous caches fail with an activation gap; it never
chooses the highest version or edits settings. Cache resolution alone is not host
registration or a guarantee of automatic discovery.

For this route, start a fresh chat with `$idea-man` followed by the task. Substantive
tasks should show actual resolver and relevant installed specialist/procedure reads
in their trace. A correct answer or enabled status alone does not prove workflow use.
